🌸 เรียน JavaScript ทีละขั้น

เปิดไฟล์นี้ในเบราว์เซอร์ → แก้โค้ด → กด Run ดูผล

บทที่ 1 — ตัวแปร (Variable)

ตัวแปรคือ "กล่อง" เก็บข้อมูล
ใช้ let ประกาศตัวแปร แล้วใส่ค่าด้วย = 
let ชื่อ = "ค่า"
✏️ แบบฝึกหัด: สร้างตัวแปรชื่อ myName ใส่ชื่อตัวเองเข้าไป แล้ว console.log มันออกมา

let myName = "ชื่อกู"
console.log(myName)
ตัวแปรเก็บได้หลายแบบ:
• string = ข้อความ → ใส่ใน " "
• number = ตัวเลข → ใส่ตรงๆ
• boolean = จริง/เท็จ → true หรือ false
✏️ แบบฝึกหัด: สร้าง 3 ตัวแปร ชื่อ age (อายุ), score (คะแนน), isAwesome (เท่มั้ย) แล้ว log ทั้งหมด
let age = 20
let score = 9999
let isAwesome = true

บทที่ 2 — การคำนวณ

JS คำนวณได้เหมือนเครื่องคิดเลข: + - * /
แล้วยังมี % (เหลือจากหาร) และ ** (ยกกำลัง)
✏️ แบบฝึกหัด: คำนวณ XP ที่ได้จาก quest
baseXP = 100, bonus = 50, สมมติทำ 3 quest → totalXP = ?
let totalXP = (baseXP + bonus) * questCount

บทที่ 3 — เงื่อนไข (if/else)

if ใช้เช็คเงื่อนไข ถ้าจริงก็ทำ ถ้าเท็จก็ข้าม 
if (เงื่อนไข) {
  // ทำถ้าจริง
} else {
  // ทำถ้าเท็จ
}
✏️ แบบฝึกหัด: ถ้า score >= 80 ให้พิมพ์ "ผ่าน" ไม่งั้นพิมพ์ "ไม่ผ่าน"
ลองเปลี่ยนค่า score แล้วรันดูผลต่างกัน

บทที่ 4 — ฟังก์ชัน (Function)

ฟังก์ชันคือ "สูตร" ที่เขียนครั้งเดียว เรียกใช้ได้กี่ครั้งก็ได้ 
function ชื่อ(input) {
  return ผลลัพธ์
}
✏️ แบบฝึกหัด: เขียนฟังก์ชัน calcXP รับ minutes แล้ว return XP (1 นาที = 2 XP)
return minutes * 2

บทที่ 5 — Array (รายการ)

Array คือรายการของข้อมูลหลายชิ้นในกล่องเดียว
เข้าถึงด้วย index เริ่มจาก 0
