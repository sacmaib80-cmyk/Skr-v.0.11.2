# โจทย์จริง TOI-Zero (ระดับ A1)

โจทย์จาก TOI National Grader (โครงการ TOI-Zero) — เอามาเรียงใหม่ **จากง่าย → ยาก**
(ไม่ใช่เรียงตามเลขไฟล์ต้นฉบับ เพราะเลขไฟล์สลับง่าย-ยาก)

> **อินพุต:** โจทย์จริงอ่านค่าจากคีย์บอร์ด แต่ที่นี่ผมใส่ค่าให้เป็น "ตัวแปร" ด้านบนไฟล์ก่อน
> เพื่อให้โฟกัสที่ *logic* ล้วนๆ (ยังไม่ต้องยุ่งกับการอ่าน input ซึ่งซับซ้อนกว่า)

## ทำยังไง
1. เปิดไฟล์ อ่านโจทย์ + ตัวอย่างในคอมเมนต์
2. เขียนโค้ดตรง `👇` ให้ `console.log` ออกมาตรงกับ `ต้องได้: ...`
3. รัน: `npx ts-node learn-ts/a1/toi/01-max-of-three.ts`
4. ลองเปลี่ยนค่าตัวแปรอินพุตด้านบน แล้วเช็คกับตัวอย่างอื่นในโจทย์
